      개념 노트

      게임을 하면서 확인해 볼 스마트팜의 핵심 원리예요.

      스마트팜 자동 제어의 순서

      센서 측정 → 데이터 전송 → 기준값 비교 → 제어 명령 → 장치 작동 → 환경 변화 → 센서 재측정

      아래쪽 ‘자동 제어 흐름’ 막대에서 이 순서가 실제로 진행되는 모습을 볼 수 있어요. 게임 속 센서는 게임 시간 약 24분(1배속 기준 1초)마다 값을 측정해 제어 장치로 보냅니다.

      꼭 알아 둘 개념

      1. 스마트팜은 정보 통신 기술 등을 농업에 활용해 작물이 자라는 환경을 관리하는 농업 시스템이에요.
      2. 토양 습도 센서는 흙 속 수분 상태를 측정해요.
      3. 온도 센서는 농장(온실)의 온도를 측정해요.
      4. 제어 장치는 센서 정보를 설정된 기준값과 비교해 장치를 작동시켜요.
      5. 워터 펌프는 물을 공급하는 장치예요.
      6. 스마트폰으로 농장 상태를 확인하고 멀리서도 장치를 제어할 수 있어요.
      7. 자동화 시스템은 센서 측정값과 설정 조건에 따라 장치를 스스로 작동시켜요.

      게임 속 습도(%)와 영양 상태(%)는 수업용으로 만든 가상 지표예요. 실제 토양 습도 센서의 값은 센서 종류와 흙의 성질에 따라 다르게 읽히고, 실제 적정 환경은 품종·생육 단계·재배 방식에 따라 달라져요. 작물의 성장 시간, 수확량, 가격(금)도 게임 진행을 위해 정한 가상 값이에요. 현실 시간 60초가 게임 속 하루이고, 작물은 실제보다 훨씬 빨리 자라요.

      돌발 날씨와 기술

      한파·폭염·건조한 바람·장마가 가끔 찾아와요. 날씨 예보가 뜨면 자동 제어 기준값을 미리 확인해 보세요. 사람이 계속 지켜보지 않아도 센서와 제어 장치가 농장을 지켜 주는 것이 자동화의 장점이에요. 보온 커튼, 차광막, LED 생장등, 태양광 패널처럼 실제 스마트팜에서 쓰는 기술을 상점에서 설치할 수 있어요(효과의 크기는 게임용으로 단순화했어요).
